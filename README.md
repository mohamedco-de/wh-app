# بوت واتساب لتحميل الفيديوهات

ترسل له رابط (تيك توك / انستا / تويتر / يوتيوب / فيسبوك / ريديت / سناب ...) ويرد عليك بالفيديو.

## التثبيت على تيرمكس (أمر واحد)
```
pkg install -y git && git clone https://github.com/USERNAME/wa-video-bot && cd wa-video-bot && bash install.sh
```
يسألك عن مفتاح loader.to (اختياري)، وبعدها شغّله بـ:
```
bash start.sh
```
أول مرة يسألك في الكونسول عن رقمك (دولي بدون +) ثم يطلع كود ربط: واتساب ← الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف.
الخروج من الجلسة وترك البوت شغال: `Ctrl+B` ثم `D`، والرجوع بـ `bash start.sh`.

## الأوامر
- `.rmbg` (أو `.ازالة`): إزالة الخلفية، أرسل صورة والأمر في الكابشن أو رد على صورة. يرجع PNG شفاف كملف.
- `.رفع` (أو `.up`): يرفع الصورة على img.svif.cloud ويرجع الرابط المباشر.
- `.ai <رسالتك>`: محادثة مع Gemini، وتقدر ترفق صورة. `.ai مسح` يمسح الذاكرة.
- `.اوامر`: قائمة الأوامر.

## إضافة أو تعديل أوامر (بدون لمس index.js)
البوت يفحص مجلد `lib` تلقائياً: أي ملف `.js` تحطه فيه يصدّر أمر (`name` + `run`) يتسجّل ويشتغل خلال ثواني بدون إعادة تشغيل، وتعديله أو حذفه ينعكس مباشرة.
- انسخ `lib/_example.js` باسم جديد بدون `_` (مثال `lib/hello.js`) وعدّل عليه.
- الملفات اللي تبدأ بـ `_` والملفات المساعدة (اللي ما تصدّر أمر) يتجاهلها.
- الأمر يظهر في `.اوامر` تلقائياً من خانة `help`.
- لو في الملف خطأ برمجي يطبعه في الكونسول ويبقي النسخة القديمة شغالة.
- تعديل ملفات index.js نفسه يحتاج إعادة تشغيل.

## استخدام
- أرسل رابط فيديو في محادثة البوت (أو لنفسك لو ربطت رقمك).
- أقل من 15MB يرسله كفيديو، أكبر يرسله كملف.

## إعدادات اختيارية (في ملف .env)
- `MAX_MB` أكبر حجم (افتراضي 60)
- `MAX_SECONDS` أطول مدة (افتراضي 900)
- `ALLOW_GROUPS=1` يشتغل في القروبات
- `LOADER_API_KEY` مفتاح loader.to للاحتياط
- `REMOVEBG_API_KEY` مفتاح remove.bg
- `GEMINI_API_KEY` مفتاح Gemini، و`GEMINI_MODEL` لتغيير الموديل (افتراضي gemini-flash-latest)
- `YTDLP_PATH` مسار yt-dlp لو مو في PATH

## تنبيه
المكتبة غير رسمية، استخدم رقم احتياطي مو الأساسي.
