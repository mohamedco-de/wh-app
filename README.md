# بوت واتساب لتحميل الفيديوهات

ترسل له رابط (تيك توك / انستا / تويتر / يوتيوب / فيسبوك / ريديت / سناب ...) ويرد عليك بالفيديو.

## التثبيت على تيرمكس (أمر واحد)
```
pkg install -y git && git clone https://github.com/USERNAME/wa-video-bot && cd wa-video-bot && bash install.sh
```
يسألك عن مفتاح loader.to (اختياري)، وبعدها شغّله بـ:
```
bash start.sh
```
أول مرة يسألك في الكونسول عن رقمك (دولي بدون +) ثم يطلع كود ربط: واتساب ← الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف.
الخروج من الجلسة وترك البوت شغال: `Ctrl+B` ثم `D`، والرجوع بـ `bash start.sh`.

## استخدام
- أرسل رابط فيديو في محادثة البوت (أو لنفسك لو ربطت رقمك).
- أقل من 15MB يرسله كفيديو، أكبر يرسله كملف.

## إعدادات اختيارية (في ملف .env)
- `MAX_MB` أكبر حجم (افتراضي 60)
- `MAX_SECONDS` أطول مدة (افتراضي 900)
- `ALLOW_GROUPS=1` يشتغل في القروبات
- `LOADER_API_KEY` مفتاح loader.to للاحتياط
- `YTDLP_PATH` مسار yt-dlp لو مو في PATH

## تنبيه
المكتبة غير رسمية، استخدم رقم احتياطي مو الأساسي.
